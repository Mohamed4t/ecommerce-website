#  KAIRA - E-commerce Website

A responsive e-commerce website built as a front-end project using HTML, CSS and JavaScript.

##  Features

-  Home page
-  Product showcase
-  Shopping cart interface
-  Login page (UI only)
-  Sign up page (UI only)
-  Message / contact page
-  Responsive design
-  Custom CSS styling
-  Basic cart price calculation with JavaScript

##  Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

##  Project Structure

```text
ecommerce-website/
│
├── img/
├── index.html
├── style.css
├── cart.html
├── cart.css
├── login.html
├── login.css
├── Signin.html
```

Current Status

This project is currently a front-end/static website.

The Login and Sign Up pages are currently UI only and are not connected to a database or backend.

The shopping cart currently uses JavaScript for basic quantity and price calculations.
